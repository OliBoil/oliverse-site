## Un hogar para el trabajo

Oliverse es la web que estás explorando ahora: un espacio rápido y accesible para proyectos prácticos y notas de aprendizaje. Está construida con Astro, se mantiene en GitHub y se publica como web estática.

## Por qué esta tecnología

- **Astro** mantiene la web rápida y facilita gestionar contenido en Markdown.
- El contenido **bilingüe** permite mantener versiones equivalentes en español e inglés.
- El diseño prioriza **velocidad, accesibilidad y una experiencia coherente** en móvil y escritorio.

El primer objetivo es crear un portfolio y diario de aprendizaje limpios. Cada actualización se revisa localmente antes de publicarse mediante un despliegue automatizado. Más adelante, los experimentos independientes podrán crecer sin complicar la web principal.
