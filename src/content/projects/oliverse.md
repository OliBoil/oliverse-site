## A home for the work

Oliverse is the site you are exploring now: a fast, accessible home for practical projects and learning notes. It is built with Astro, maintained on GitHub and published as a static website.

## Why this stack

- **Astro** keeps the site fast and makes Markdown content easy to maintain.
- **Bilingual content** keeps equivalent Spanish and English versions together.
- The design prioritises **speed, accessibility and a consistent experience** across mobile and desktop.

The first milestone is a clean portfolio and learning log. Each update is reviewed locally before being published through an automated deployment. Later, independent experiments can grow without making the main site harder to maintain.
